{% translate "This notice explains what information the OSEA competition platform holds, why, who can see it, and how long it is kept. It covers this site only, not OSEA's main website." %}

{% translate "What we collect" %}

  • {% translate "Teacher coaches: name, school email address, the schools they coach for and their role there, and a password (stored only in scrambled form)." %}
  • {% translate "Students: first name, last initial, grade, in-game name and, for some games, an optional rank. Students do not have accounts. We do not collect birthdates, home addresses, phone numbers, photos or student email addresses." %}
  • {% translate "Schools: name, city, school board, OSEA membership and payment records." %}
  • {% translate "Competition records: teams, rosters, match times, results and announcements." %}

{% translate "Consent" %}

{% translate "Coaches enter student information. Before registering a team, the coach confirms that the school has the consent its own policies require for students to take part and for this information to be shared with OSEA." %}

{% translate "Why we use it" %}

{% translate "Only to run school esports competitions: confirming coaches and school memberships, registering teams, checking eligibility rules (such as grade), scheduling matches, recording results and contacting coaches. We do not sell information, show advertising, or use it for marketing." %}

{% translate "Who can see what" %}

  • {% translate "Anyone can see published competitions, team names, school names, schedules, results and standings, and announcements OSEA marks as public." %}
  • {% translate "Student names and rosters are never public. They are visible to coaches approved for that school and to OSEA administrators." %}
  • {% translate "Coach contact details are never public. When two teams play each other, their coaches can see each other's name and email address for that match, so they can arrange a time." %}
  • {% translate "OSEA administrators can see everything, in order to run the competitions. They must use two-step sign-in." %}

{% translate "Where it is stored" %}

{% translate "The platform and its database are hosted in Toronto, Canada (DigitalOcean), with daily backups. Connections to the site are encrypted. Email notifications are sent through OSEA's Google Workspace account; some notifications about roster changes include a student's first name and last initial." %}

{% translate "Cookies" %}

{% translate "The site uses only the cookies needed to keep you signed in and protect forms. There are no advertising or tracking cookies, and no analytics." %}

{% translate "How long we keep it" %}

{% translate "Coaches mark students who have left the school; they are then no longer available for new teams. Past rosters and results are kept as the competition's history. A permanent activity log records who changed what, so changes can be traced." %}
